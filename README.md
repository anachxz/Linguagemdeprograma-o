## 📚 Sobre o projeto

Este repositório reúne os exercícios, atividades e projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas**.

Aqui registro minha evolução no aprendizado de **desenvolvimento web**, colocando em prática os conteúdos estudados em aula e explorando novas possibilidades conforme avanço na graduação.

O objetivo é manter uma documentação do meu aprendizado e construir, aos poucos, meu portfólio na área de tecnologia.
